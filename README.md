# aibolno.ru

Статичная витрина: четыре страницы, один файл стилей, без сборки и без зависимостей.

```
index.html    главная
metod.html    бесплатный метод
sostav.html   что входит
oplata.html   как купить
styles.css    стили (токены, тёмная тема)
files/        файл метода, который отдаётся по кнопке
```

Открывается двойным щелчком по `index.html`. Публикуется как есть — ничего собирать не нужно.

Внешняя зависимость одна: шрифты Google (Inter, Literata, JetBrains Mono).
Счётчиков, аналитики, форм и сторонних скриптов нет.
